# Game of Life with Raylib

Simple Game of Life implementation for Linux as a beginner project. Raylib and g++ are the only dependencies.

To build, run make. This will produce an executable named 'gol'.

Here are the controls:

- Zoom: Mouse wheel
- Increase/decrease evolution speed: Shift + Mouse wheel
- Move around: Hold left click
- Make cell alive: Shift + Left click (can hold and drag)
- Kill cell : Right click (can hold and drag)
- Toggle grid visibility: G
- Pause/play: Spacebar
- Center view: C
- Reset: R
- Change cell color: 1-9
